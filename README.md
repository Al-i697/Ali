# نظام توزيع الغاز: العملاء والديون

برنامج ويب يشتغل من الجوال والآيباد والكمبيوتر، مبني على شغل شركة توزيع الغاز:

- **تنظيم التوزيع حسب المناطق:** شاشة «توزيع اليوم» تجمع الطلبات حسب المنطقة، والسائق يضغط «تسليم» ويحدد دفع كامل أو آجل أو جزء.
- **تسجيل الديون والسداد:** كل دين وكل سداد قيد ثابت ما ينحذف، وإذا انلغى يبقى ظاهر مع اسم من ألغاه والسبب.
- **متابعة الديون:** أعمار الديون (30/60/90 يوم)، وعود السداد، تذكير واتساب بضغطة، كشف حساب للطباعة، وتصدير Excel.
- **توقع الطلبات:** النظام يحسب كل كم يوم يطلب العميل وينبّهكم قبل ما يتصل.

## تشغيل تجريبي على جهازك

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
export DJANGO_DEBUG=1
python manage.py migrate
python manage.py seed_demo          # بيانات تجريبية للتجربة فقط (اختياري)
python manage.py runserver
```

افتح http://127.0.0.1:8000. حسابات التجربة (كلمة السر `demo1234`): `owner` مدير الشركة، `manager` مدير، `driver` سائق.

**للعمل الحقيقي:** لا تشغّل `seed_demo`. أنشئ حساب مدير الشركة بهذا الأمر، وبعدها أضف المناطق والمنتجات والسائقين من داخل البرنامج:

```bash
python manage.py createsuperuser
```

## التشغيل على سيرفر حقيقي

السائقين يحتاجون رابط يفتحونه من الجوال، فالنظام لازم يشتغل على سيرفر. الخطوات الكاملة، وشرح العلاقة بين GitHub والسيرفر والجوالات، والنسخ الاحتياطي، في **[DEPLOY.md](DEPLOY.md)**.

باختصار: `Dockerfile` جاهز، وقاعدة البيانات PostgreSQL عن طريق `DATABASE_URL`، وحساب مدير الشركة ينشأ تلقائي من `GASDIST_OWNER_USERNAME` و`GASDIST_OWNER_PASSWORD`. بدون `DATABASE_URL` يستخدم ملف SQLite محلي للتجربة فقط.

## بديل بدون سيرفر: شيت + نموذج Google

مجلد [`sheets/`](sheets/) فيه نسخة مبسطة تشتغل على Google Sheets وGoogle Forms بدون استضافة ولا دفع: السائق يسجل من نموذج، والمدير يشوف الأرصدة والمتأخر أكثر من 30 يوم من الشيت. التفاصيل في [`sheets/GUIDE.md`](sheets/GUIDE.md).

- `gas-ledger-template.xlsx`: القالب الفاضي للاستخدام.
- `gas-ledger-DEMO.xlsx`: نفس القالب ببيانات وهمية للمعاينة فقط.
- `verify_template.py`: يحسب المعادلات في LibreOffice ويقارنها بحسابات البرنامج (يحتاج `pip install openpyxl` ولا يدخل في `requirements.txt`).
