# برنامج المقهى

برنامج مبيعات وحسابات لمقهى/مطعم، يشتغل على **الآيباد وحده بدون سيرفر وبدون إنترنت** (بعد أول فتح).
العملة: الريال العماني بثلاث خانات (بيسة). كل المبالغ تُخزَّن أعداداً صحيحة بالبيسة.

## كيف يشتغل
- موقع ثابت (HTML/CSS/JS) يُحفَّظ في الآيباد عبر Service Worker، وكل البيانات تُحفظ في **IndexedDB** على الجهاز نفسه.
- الأرصدة (ديون العملاء، المستحق للموردين، مخزون الأصناف، حساب الصندوق) **تُحسب من الحركات** ولا تُخزَّن، فما تنحرف.
- الفواتير مرقمة تسلسلياً (تبدأ 1001)، والإلغاء يبقى له أثر. الوردية تفتحها وتقفلها أنت.
- الأصناف: **بالعدد** (لها كمية افتتاحية تنخصم مع كل بيع) أو **تحضيري** (مثل المشاوي: بلا مخزون)، مع أحجام (صغير/وسط/كبير) وصورة أو إيموجي.
- حسابات المدير والكاشير محلية (الرمز مشفّر PBKDF2 مع ملح)، مع **رمز استرجاع** يظهر مرة وحدة عند الإعداد.
- الأرباح والتقارير للمدير فقط. الكاشير يرى: البيع، الفواتير، العملاء، الوردية.

## تركيبه على الآيباد (مرة وحدة)
1. افتح رابط الموقع في **Safari** (يحتاج إنترنت هذه المرة فقط).
2. زر المشاركة ⬆︎ ← **إضافة إلى الشاشة الرئيسية**.
3. افتحه **من الأيقونة دائماً**. بيانات Safari وبيانات الأيقونة منفصلة عن بعض، فلا تستخدم الاثنين.
4. أول تشغيل: أدخل اسم المتجر وحساب المدير، واكتب **رمز الاسترجاع** في مكان آمن.

> الآيباد الجيل السادس يدعم حتى iPadOS 17، وهذا كافٍ.

## النسخ الاحتياطي (مهم)
بما أن كل شيء على الآيباد، النسخة الاحتياطية هي أمانك لو ضاع الجهاز أو انمسحت بياناته:
- **الإعدادات ← حفظ نسخة احتياطية الآن** ← قائمة المشاركة: احفظها في «الملفات»/iCloud أو أرسلها لنفسك على واتساب.
- يذكّرك البرنامج بعد إقفال كل وردية، وتنبيه في الرئيسية إذا مرّ يومان بدون نسخة.
- **الاسترجاع**: من شاشة الإعداد الأولى (على جهاز جديد) أو من الإعدادات.
- **الاستيراد من البرنامج القديم**: الإعدادات ← اختيار ملف النسخة القديمة (JSON): تنتقل الأصناف والعملاء والموردون.

## الطباعة والمشاركة
- **واتساب**: يفتح المحادثة مباشرة برسالة الفاتورة (`wa.me`).
- **مشاركة**: ملف PDF (أو صورة PNG بعرض 576 نقطة من الإعدادات) عبر قائمة المشاركة، فتقدر تفتحه في تطبيق الطابعة.
- **طباعة**: ورق حراري 72mm عبر نافذة طباعة iOS (**AirPrint**).
- ملاحظة: Safari على الآيباد لا يدعم Web Bluetooth، فالطباعة المباشرة على طابعة بلوتوث من الموقع غير ممكنة. الطرق المتاحة: طابعة تدعم AirPrint، أو مشاركة الفاتورة (PDF/صورة) لتطبيق الطابعة.

## نشره (GitHub Pages)
المستودع → **Settings ← Pages ← Build and deployment**: Source = *Deploy from a branch*، اختر الفرع، والمجلد **`/docs`**، ثم Save.
الرابط يكون: `https://<اسم-الحساب>.github.io/<اسم-المستودع>/` — كل المسارات نسبية فتشتغل تحت أي مسار.

## التطوير
```
src/            المصدر: body.html (الهيكل) + core.js (الحسابات) + db.js (التخزين) + ui.js (الواجهة) + css/ + sw.js
tools/build.py  يجمّع src → docs (index.html, app.css, app.js, sw.js, manifest, fonts, vendor, icons)
tools/make_icons.js   يولّد أيقونات الشاشة الرئيسية
tests/          Playwright: e2e (أول تشغيل/حفظ/نسخ/بدون إنترنت)، ui (المسارات)، perf (أداء)، monkey (لمسات عشوائية)، update (تحديث النسخة)
docs/           الناتج الجاهز للنشر (يُبنى بـ build.py، لا يُعدَّل يدوياً)
```
```
python3 tools/build.py                       # بناء docs
cd docs && python3 -m http.server 8123       # تشغيل محلي
node tests/fixture.js 300                    # بيانات تجريبية للاختبار (تُكتب في /tmp)
node tests/e2e.js && node tests/ui.js        # الاختبارات (Playwright مثبّت عالمياً: NODE_PATH=$(npm root -g))
node tests/perf.js 100000 4                  # أداء مع 100 ألف فاتورة ومعالج أبطأ 4 مرات
```
كل مرة يتغير الكود، `build.py` يغيّر رقم النسخة فيتحدّث البرنامج على الآيباد وتظهر له رسالة «تطبيق التحديث».
