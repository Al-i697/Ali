# المنصة: بنية الموقع الموحَّد

موقع واحد برابط واحد: فهرس المقررات، والدروس التفاعلية، ثم سجل المعلم (لوحة الصف). هذا المجلد يجمعها.

## الملفات

| الملف | وظيفته |
|---|---|
| `catalog.json` | فهرس المقررات: المادة ← الصف ← الوحدة ← الدرس. الدرس الذي له `page` جاهز، وغيره يظهر «قريباً». أُخذت قوائمه من منظومة التحضير القديمة (كيمياء ١٠ و١١ و١٢ وعلوم بيئية ١١). |
| `index.src.html` | الصفحة الرئيسية الحالية (ستُستبدل بالفهرس بعد اعتماد النماذج). |
| `build.py` | يبني `dist/`: الرئيسية + الدروس الخمسة + `shared/`. |
| `preview/` | نماذج التصميم (الرئيسية، درج الصف، شاشات سجل المعلم). نموذج للنظر فقط، ولا يحفظ شيئاً. |

## الأجزاء المشتركة

صور الملصقات (نحو ٧٨٠KB، واحدة في كل الدروس) تُحمَّل مرة واحدة من `shared/stickers_assets.js` بدل نسخها داخل كل درس. لذلك صار الدرس نحو ٣٥٠–٧٠٠KB بدل ١–١.٥MB. كل درس يبقى قابلاً للبناء مستقلاً:

```
cd lessons/3-3-reacting-masses
python3 build.py            # lesson33.html: ملف واحد مستقل (للاختبارات)
python3 build.py --shared   # lesson33.slim.html: نسخة خفيفة تحمّل shared/stickers_assets.js
python3 ../../site/build.py # يبني site/dist كاملاً
```

## بيانات المعلم

بيانات الطلاب حساسة. لا تُحفظ في المستودع ولا تُنسخ من أي موقع قديم.
