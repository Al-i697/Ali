# المنصة: بنية الموقع الموحَّد

موقع واحد برابط واحد: فهرس المقررات، والدروس التفاعلية، ثم سجل المعلم (لوحة الصف). هذا المجلد يجمعها.

## الملفات

| الملف | وظيفته |
|---|---|
| `catalog.json` | فهرس المقررات: المادة ← الصف ← الوحدة ← الدرس. الدرس الذي له `page` جاهز، وغيره يظهر «قريباً». أُخذت قوائمه من منظومة التحضير القديمة (كيمياء ١٠ و١١ و١٢ وعلوم بيئية ١١). |
| `platform/` | المنصة نفسها: الرئيسية والفهرس، لوحة الصف داخل الدرس، وشاشات سجل المعلم. `src/logic.js` منطق نقي (الشعب والمشاركة والسلوك والملخص والتقارير والنسخ الاحتياطي واستيراد نسخة الموقع القديم)، و`src/store.js` الحفظ في المتصفح، و`src/app_*.js` الواجهة. |
| `index.src.html` | الصفحة الرئيسية القديمة (قائمة الدروس فقط). لم تعد تُبنى. |
| `build.py` | يبني `dist/`: الرئيسية + الدروس الخمسة + `shared/`. |
| `preview/` | نماذج التصميم (الرئيسية، درج الصف، شاشات سجل المعلم). نموذج للنظر فقط، ولا يحفظ شيئاً. |

## الأجزاء المشتركة

صور الملصقات (نحو ٧٨٠KB، واحدة في كل الدروس) تُحمَّل مرة واحدة من `shared/stickers_assets.js` بدل نسخها داخل كل درس. لذلك صار الدرس نحو ٣٥٠–٧٠٠KB بدل ١–١.٥MB. كل درس يبقى قابلاً للبناء مستقلاً:

```
cd lessons/3-3-reacting-masses
python3 build.py            # lesson33.html: ملف واحد مستقل (للاختبارات)
python3 build.py --shared   # lesson33.slim.html: نسخة خفيفة تحمّل shared/stickers_assets.js
python3 ../../site/build.py # يبني site/dist كاملاً
```

## الاختبارات

```
python3 site/build.py                   # يبني site/dist
node site/platform/tests/logic.test.js  # اختبارات المنطق (٢٠)
node site/platform/tests/e2e.js         # اختبارات المتصفح (١٨): شعبة، درج، شريحة، ملخص، تقرير، تصدير، استيراد، نصوص ضارة، بيانات تالفة
```

## كيف يعمل الدرس داخل المنصة

الدرس يُفتح في إطار (iframe) من الموقع نفسه، والمنصة تضيف زر «الصف» في شريطه العلوي وتبني الدرج بجانبه. لا يُنسخ أي كود للصف داخل الدروس، فكل درس جديد يعمل مع الدرج بلا تعديل. الدرس يحتاج نحو ١٠٠٠px عرضاً، فإذا ضاق المكان بسبب الدرج تُصغَّر نافذة الدرس بدل أن يُقطع شريطه.

## بيانات المعلم

بيانات الطلاب حساسة. لا تُحفظ في المستودع. تُحفظ في متصفح المعلم (localStorage) مع نسخة احتياطية يصدّرها ويستوردها. الاستيراد يقبل نسخة هذا الموقع ونسخة موقع «الإدارة الصفية» القديم، ويضيف ولا يحذف.
