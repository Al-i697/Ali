# الدرس ٣-٣ · حسابات تتضمن كتلاً متفاعلة (كيمياء الصف العاشر)

درس تفاعلي من ٣٤ شريحة يتبع ترتيب عرض NotebookLM (الغلاف، السندويش، خطوات الصيغة، Mg/O وSi/O، ٦ g Si مع ٥.٣ g O، Fe + S، القاعدة، CuO + C، ص٤٨، ص٧٨، الخلاصة)،
مضافاً إليه ما في كتاب الطالب وملفك: كتلة الناتج من المعادلة (مثالا ٣-٢ و٣-٣ وأسئلة ٣-٨ إلى ٣-١٠)، وجزء الكتل من ورقة العمل ٣-٣ (سولفاي)، ومختبر افتراضي لنشاط ٣-٢ (إثرائي)، وأشكال جسيمات، وسباق، وتذاكر خروج، وأسئلة امتحانات.

```bash
python3 build.py [--standalone]   # lesson33.html
python3 tools/rekey.py            # يعيد توليد src/assets.js من art-src/ (الخبز والجبن والسندويش والدورقان)
node tools/test.js                # كل التفاعلات (٣٤ اختباراً) مع فحص أن شيئاً لا يخرج من الإطار بعد الخطوات
node tools/overflow.js            # حدود الشرائح
node tools/contrast.js            # تباين النصوص فوق الخلفية المتحركة
node tools/residue.js             # لا بقايا حركات بعد التنقل السريع
node ../_core/tools/stk_check.js $PWD/lesson33.html 34   # الملصقات لا تقع على النص
```

| الملف | ما فيه |
|---|---|
| `src/config.js` | الفصول (٩) والخلفية واللوحة والملصقات لكل فصل/شريحة |
| `src/helpers.js` | Ar وMR، `bindSeq` (خانات تُفتح بالترتيب)، `bindMatch` (مطابقة بالسحب)، `formulaTable` (جدول استنباط الصيغة) |
| `src/part_a.js` | الغلاف، السندويش (ملعب تفاعلي)، استنباط الصيغة، تذكرة ١ |
| `src/part_b.js` | المحددة والفائضة: أشرطة، قاعدة، ميزان، أشكال جسيمات، تصنيف، تذكرة ٢ |
| `src/part_c.js` | الكتلة من المعادلة: سلسلة التحويل، الأمثلة، الأسئلة ٣-٨ إلى ٣-١٠، سولفاي |
| `src/part_d.js` | المختبر الافتراضي وحساباته، والسباق |
| `src/past.js` | أسئلة امتحانات سابقة (الأولى حقيقية، والثانية على نمطها) |
| `src/tail.js` | التذكرة النهائية والواجب |

ملاحظات المحتوى: النحاس Cu = 63.5 كما في الكتاب (ونقبل ٦٤ أيضاً)، وأجوبة الأسئلة تُقبل بتفاوت ٠.٨٪ تقريباً. شريحة السندويش تُغيّر العدد بالأزرار بدل عبارة «٤ − ٣ = ١» في العرض، وأضفنا وصفة «٢ خبز : ١ جبن» لتبرير القسمة على المعامل.

## مقارنة المصادر بالدرس

| المصدر | النقاط | أين في الدرس |
|---|---|---|
| عرض NotebookLM (١٣ شريحة) | السندويش، خطوات الصيغة، Mg/O، Si/O، ٦ g Si مع ٥.٣ g O، Fe + S، القاعدة، CuO + C، ص٤٨، ص٧٨، الخلاصة | `sand1` `steps3` `mgo` `sio2` `si6` `fes` `rule` `cuo` `fe48` `ag` `cls` |
| عرضك القديم (١١ شريحة) | نفس ما سبق، ويزيد: مثال ٣-٢ والأسئلة ٣-٨ إلى ٣-١٠ (غير موجودة في عرض NotebookLM) | `ex32` `q38` `q39` |
| كتاب الطالب ص٦١–٦٥ | استنباط الصيغة، كتل المواد في التفاعل (٥٦ : ٣٢ : ٨٨)، المحددة والفائضة، التكبير بالأطنان، مثالا ٣-٢ و٣-٣، نشاط ٣-٢، الأسئلة ٣-٨ إلى ٣-١١ | كلها؛ والناقص كان **المعادلة كنسبة مولات وكتل** فأضيف `conserve` |
| ملخص الوحدة (ص٤) وكراسة الأمثلة | حفظ الكتلة (٥٦ + ٣٢ = ٨٨)، المصطلحان، الأمثلة ٨–١٢ بالطريقة الرسمية | `conserve`، وتفصيل القاعدة في `fes` |
| كتاب النشاط | ورقة العمل ٣-٣ (حديد وكبريت، سولفاي)، تمرين ٣-٢ التناسب، ورقة العمل ٣-٤ ماء التبلور | `fe48` `solv`؛ والناقص: `prop` و`bacl` |
| دليل المعلم | أفكار التدريس (تفكك CaCO₃)، نشاط ٣-٢ (إثرائي)، الواجب | `scaleup` `lab` `labcalc` `hw` |
| الامتحانات | الصيغة من الكتل (NO₂)، كتلة الناتج (Fe₂O₃)، المحددة والفائضة، BaCl₂·2H₂O | `noo` `past1` `bacl` |
