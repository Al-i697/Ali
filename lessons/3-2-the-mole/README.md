# الدرس ٣-٢ · المول (كيمياء الصف العاشر)

درس تفاعلي من ٢٩ شريحة يتبع ترتيب عرض NotebookLM، مع تفاعل بين كل شرحين: العدّ بالوزن، مطابقة وحدات العدّ، مثلث الحساب، جدول ٣-٤ التفاعلي، أسئلة ٣-٥ إلى ٣-٧، تمرين ٣-٣ (أ)، سباق الفصل، تذكرتا خروج، وأسئلة امتحانات.
لا يحتوي مختبراً افتراضياً لأن الدرس ليس فيه تجربة عملية.

```bash
python3 build.py [--standalone]   # lesson32.html (مع --standalone بدون زر العودة إلى الصفحة الرئيسية)
python3 tools/rekey.py            # يعيد توليد src/assets.js من art-src/
node tools/test.js                # كل التفاعلات (٢٩ اختباراً)
node tools/overflow.js            # حدود الشرائح
node tools/contrast.js            # تباين النصوص فوق الخلفية المتحركة
node tools/residue.js             # لا بقايا حركات بعد التنقل السريع
```

| الملف | ما فيه |
|---|---|
| `src/config.js` | الفصول والخلفية واللوحة لكل فصل/شريحة |
| `src/helpers.js` | تحليل الصيغ وحساب Mr (`MR('CuSO4.5H2O')`)، وصفوف الإجابات المتسلسلة `bindRows` |
| `src/mole_a.js` | الشرائح ١–١٢ بترتيب العرض |
| `src/mole_b.js` | التذاكر والمثال المحلول والأسئلة ٣-٥ إلى ٣-٧ وتمرين ٣-٣ والسباق |
| `src/past.js` | أسئلة امتحانات سابقة (الأولى حقيقية، والثانية على نمطها) |
| `src/tail.js` | التذكرة النهائية والواجب |
| `art-src/` | شرائح العرض التي قُصّت منها الرسوم |

كل الأرقام والإجابات تُحسب من قيم Ar بالدالة `MR()` ولا تُكتب يدوياً.


## المظهر (القالب المشترك، نوفمبر ٢٠٢٦)
أُعيد بناء الدرس بنفس قالب الدروس الأخيرة (الوحدات ١ و٢ و٤) دون تغيير المحتوى ولا ترتيب الشرائح:
- **البناء:** `build.py` يستدعي `../_core/tools/u4build.py` بالخيارين `skin='cards'` (خلفيات حية خلف بطاقات ملوّنة صلبة) و`shuffle=True` (خلط ترتيب خيارات الأسئلة فلا تكون الإجابة الصحيحة دائماً الأولى؛ الإجابات مربوطة بـ `data-i` فلا يتأثر التصحيح).
- **الخلفيات:** صور المعلم موزّعة بلا تكرار داخل الدرس على 10 شريحة (goals، weigh، graphite، mole، ar، q36، act31، past1، final، hw)، وبقية الشرائح بخلفيات لونية سادة (`p_plain_a..d`) لأنه لا يحب تكرار الصور؛ الشرائح الكثيفة بالتفاعل والجداول خلفيتها سادة ليبقى النص مقروءاً. الخطة في `bgId` داخل `src/config.js`.
- **النقاط بنقرة:** الأهداف (`.gi`) وخلاصة الواجب (`.panel.dark li`) تظهر نقطة نقطة مثل عرض بوربوينت (`pts` في `config.js`).
- **الاختبارات:** تعمل على `?pts=all`، وتختار الخيارات بـ `data-i` لا بترتيبها على الشاشة، وفيها فحص أن شيئاً لا يخرج من الإطار بعد الخطوات (`fits`).
- **الفحوص:** `overflow` و`contrast` (يتجاهل نصاً لم يظهر بعد) و`residue` تعمل على `?pts=all` ويذكر `contrast` رقم الشريحة ومعرّفها.
- **تعديلات صغيرة على الشرائح** لتناسب البطاقات: شريحة «كم عدد…؟» (count): الصور أصغر لتتسع التغذية الراجعة؛ شريحة أفوجادرو (avo): العمود الجانبي أعرض

## التدرّج: نقاط تظهر نقرة نقرة (نوفمبر ٢٠٢٦)

بطلب المعلم، لا تظهر شرائح الشرح والحل كلها دفعة واحدة؛ بل تنزل **نقطة نقطة** بزر «التالي» (أو سهم اليسار)، ويرجع «السابق» نقطة. عدّاد النقاط يظهر في الشريط السفلي. الترتيب العام في شرائح المسائل والأمثلة: **المسألة أولاً ← خريطة الحل ← الخطوات واحدة واحدة ← الخلاصة آخراً**، وفي شرائح الأسئلة: **سؤال سؤال**. تفاعلات الطلاب (سحب، إدخال أرقام، اختيار) ما تغيّرت.

القاعدة التقنية (في `src/config.js`): في الشريحة ذات العمودين تُعدّ النقاط من العمود الأول ثم الثاني (مسألة/نص ← جدول/خطوات)، بدون سطور التغذية الراجعة ولا الأجزاء المخفية ولا شرائط Ar المرجعية (تبقى ظاهرة). الجداول تنزل صفاً صفاً، والامتحانات بطاقة بطاقة.
