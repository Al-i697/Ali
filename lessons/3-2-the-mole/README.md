# الدرس ٣-٢ · المول (كيمياء الصف العاشر)

درس تفاعلي من ٢٩ شريحة يتبع ترتيب عرض NotebookLM، مع تفاعل بين كل شرحين: العدّ بالوزن، مطابقة وحدات العدّ، مثلث الحساب، جدول ٣-٤ التفاعلي، أسئلة ٣-٥ إلى ٣-٧، تمرين ٣-٣ (أ)، سباق الفصل، تذكرتا خروج، وأسئلة امتحانات.
لا يحتوي مختبراً افتراضياً لأن الدرس ليس فيه تجربة عملية.

```bash
python3 build.py [--standalone]   # lesson32.html (مع --standalone بدون زر العودة إلى الصفحة الرئيسية)
python3 tools/rekey.py            # يعيد توليد src/assets.js من art-src/
node tools/test.js                # كل التفاعلات (٢٩ اختباراً)
node tools/overflow.js            # حدود الشرائح
node tools/contrast.js            # تباين النصوص فوق الخلفية المتحركة
node tools/residue.js             # لا بقايا حركات بعد التنقل السريع
```

| الملف | ما فيه |
|---|---|
| `src/config.js` | الفصول والخلفية واللوحة لكل فصل/شريحة |
| `src/helpers.js` | تحليل الصيغ وحساب Mr (`MR('CuSO4.5H2O')`)، وصفوف الإجابات المتسلسلة `bindRows` |
| `src/mole_a.js` | الشرائح ١–١٢ بترتيب العرض |
| `src/mole_b.js` | التذاكر والمثال المحلول والأسئلة ٣-٥ إلى ٣-٧ وتمرين ٣-٣ والسباق |
| `src/past.js` | أسئلة امتحانات سابقة (الأولى حقيقية، والثانية على نمطها) |
| `src/tail.js` | التذكرة النهائية والواجب |
| `art-src/` | شرائح العرض التي قُصّت منها الرسوم |

كل الأرقام والإجابات تُحسب من قيم Ar بالدالة `MR()` ولا تُكتب يدوياً.

## مقارنة المصادر بالدرس
أُنجز الجدول في مراجعة لاحقة (بعد بناء الدرس)، وفيه كل ما قورن بالدرس.

| المصدر | النقاط | أين في الدرس |
|---|---|---|
| عرضك القديم (٦ شرائح) | تمهيد العدّ (قطع معدنية وبالونات وأرز وكربون الرصاص)، الزوج والدرزن والرزمة والمول، تعريف المول وعدد أفوجادرو، لا يمكن وزن ذرة مفردة، كتلة مول واحد (اختلاف الصيغة)، حسابات المول | `count` `weigh` `graphite` `units` `mole` `single` `ways` `t34a` `t34b` `avo` `ar` |
| عرض NotebookLM (١٥ شريحة) | إعادة تصميم لما سبق، والدرس يتبع ترتيبه | الدرس كله |
| كتاب الطالب ص٥٩–٦١ | المول وعدد أفوجادرو، الجدول ٣-٤، مثال ٣-١، الأسئلة ٣-٥ إلى ٣-٧ | `mole` `t34a` `t34b` `ex31` `q35` `q36` `q37` `chain` |
| كتاب النشاط ص٣٨–٣٩ | تمرين ٣-٣ (أ) مثلث الحساب والجدول (١١ مادة) | `formula` `tbl33a` `tbl33b`؛ والجزئيتان (ب) و(ج) في الدرس ٣-٣ |
| دليل المعلم ص٥٤–٥٥ | الأهداف ٣-٨ و٤-٨، تشبيه العملات، إعادة نتائج نشاط ٣-١ بالمولات، الواجب | `goals` `weigh` `act31` `hw` |
| الامتحانات | المول (تعريف)، مولات وكتلة الحديد، الكتلة المولية لـ Fe₂O₃، كتلة Zn وMg من المولات | `past1` |
| أسئلة نهاية الوحدة (ص٧٨) | السؤال ٢: الكربون-12 مقياساً، Mr وعدد مولات وجزيئات وذرات O في 8.8 g من CO₂ | `eou2` (أُضيفت في المراجعة) |
| **ناقص** | ورقة العمل ٣-٢ (المول والصيغ الكيميائية): غير متوفرة (ملف كتاب النشاط ينتهي عند ص٥٠) | عند إرسالها |
