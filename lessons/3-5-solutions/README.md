# الدرس ٣-٥ · حسابات تتضمن محاليل متفاعلة (كيمياء الصف العاشر)

درس تفاعلي من ٣٦ شريحة: المحاليل (المذاب والمذيب)، تركيز الكتلة g/L، التركيز المولي mol/L، المعايرة (الجهاز والخطوات)، مختبر افتراضي للنشاط ٣-٤ (معايرة HCl بـ NaOH)، حسابات المعايرة، تطبيقات (حمض الستريك، ماء التبلور، صيغة حمض عضوي)، الخريطة الكبرى لحسابات الوحدة، أسئلة امتحانات.

```bash
python3 build.py [--standalone]   # lesson35.html
node tools/test.js                # كل التفاعلات (٣٦ اختباراً) مع فحص أن شيئاً لا يخرج من الإطار بعد الخطوات
node tools/overflow.js            # حدود الشرائح
node tools/contrast.js            # تباين النصوص فوق الخلفية المتحركة
node tools/residue.js             # لا بقايا حركات بعد التنقل السريع
node ../_core/tools/stk_check.js $PWD/lesson35.html 36   # الملصقات لا تقع على النص
```

## المظهر (القالب المشترك، نوفمبر ٢٠٢٦)
أُعيد بناء الدرس بنفس قالب الدروس الأخيرة (الوحدات ١ و٢ و٤) دون تغيير المحتوى ولا ترتيب الشرائح:
- **البناء:** `build.py` يستدعي `../_core/tools/u4build.py` بالخيارين `skin='cards'` (خلفيات حية خلف بطاقات ملوّنة صلبة) و`shuffle=True` (خلط ترتيب خيارات الأسئلة فلا تكون الإجابة الصحيحة دائماً الأولى؛ الإجابات مربوطة بـ `data-i` فلا يتأثر التصحيح).
- **الخلفيات:** صور المعلم موزّعة بلا تكرار داخل الدرس على 9 شريحة (goals، cg، cm، lab0، wsburette، citric، past1، final، hw)، وبقية الشرائح بخلفيات لونية سادة (`p_plain_a..d`) لأنه لا يحب تكرار الصور؛ الشرائح الكثيفة بالتفاعل والجداول خلفيتها سادة ليبقى النص مقروءاً. الخطة في `bgId` داخل `src/config.js`.
- **النقاط بنقرة:** الأهداف (`.gi`) وخلاصة الواجب (`.panel.dark li`) تظهر نقطة نقطة مثل عرض بوربوينت (`pts` في `config.js`).
- **الاختبارات:** تعمل على `?pts=all`، وتختار الخيارات بـ `data-i` لا بترتيبها على الشاشة، وفيها فحص أن شيئاً لا يخرج من الإطار بعد الخطوات (`fits`).
- **الفحوص:** `overflow` و`contrast` (يتجاهل نصاً لم يظهر بعد) و`residue` تعمل على `?pts=all` ويذكر `contrast` رقم الشريحة ومعرّفها.
- **تعديلات صغيرة على الشرائح** لتناسب البطاقات: لا شيء يُذكر (التعديلات في CSS فقط)

## تصحيحات على المصادر
- **عرض NotebookLM، شريحة تدريب ٣-١٧ (د):** مكتوب «0.8 g من NaOH في 100 mL» والإجابة 0.2 mol/L، لكن كتاب الطالب يقول إن الحجم النهائي **1 L** فالإجابة **0.02 mol/L**. اعتُمد الكتاب (وإن كانت طبعتكم تقول 100 mL فالإجابة 0.2).
- **عرض NotebookLM:** مرجعا الصفحات خطأ: تدريب ٣-١٦ في ص٧٦ (مكتوب ص٦٩)، وسؤال ٥ نهاية الوحدة في ص٧٩ (مكتوب ص٧١).
- **ورقة العمل ٣-٥ سؤال ٣:** العرض فيه الجزءان (أ) و(ب) فقط؛ أضيف حساب تركيز NaOH (0.15 mol/L) تتميماً.
- **ورقة العمل ٣-٦:** x ≈ 2.4 تُقرَّب إلى 2 لأن الورقة تشترط عدداً صحيحاً (الفرق عن 118 g/mol يعود إلى الأخطاء التجريبية).
- ورقة العمل ٣-٥ سؤال ١(ج) (حجم الهيدروجين من الخارصين) حُلّ في الدرس ٣-٤.

ملاحظات المحاكاة: أحجام نقطة النهاية في المختبر الافتراضي (24.9 و24.6 و24.5 mL، أي تركيز HCl ≈ 0.102 mol/L) مولَّدة للعرض وليست قياسات حقيقية. لون الكاشف: أصفر ← برتقالي عند نقطة النهاية ← أحمر عند التجاوز.
