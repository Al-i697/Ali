# الدرس ٣-١ · الكتل النسبية (كيمياء الصف العاشر)

درس تفاعلي لعرضه على السبورة أو الحاسوب: ٢٩ شريحة، أسئلة وسحب وإفلات وتصويت وتذاكر خروج، مختبر افتراضي لحرق الماغنيسيوم، وأسئلة من امتحانات سابقة.
الملف الجاهز للفتح: `lesson31.html` (صفحة واحدة بلا مكتبات).

## البناء
```bash
python3 build.py            # يجمّع src/ في lesson31.html
python3 tools/rekey.py      # يعيد توليد src/assets.js من art-src/ (عند تغيير ألوان الرسوم)
```

## الاختبار (من مجلد الدرس، ويحتاج Node وPlaywright)
```bash
node tools/test.js          # كل تفاعلات الشرائح (٢٨ اختباراً)
node tools/residue.js       # لا بقايا حركات بعد التنقل السريع
node tools/overflow.js      # لا تجاوز لحدود الشريحة
node tools/contrast.js      # تباين النصوص فوق الخلفية المتحركة
node tools/perf.js          # زمن الإطار لكل خلفية ولكل مستوى جودة
node tools/tier_test.js     # زر الخلفية (كاملة / هادئة / ثابتة) وحفظ الاختيار
```

## هيكل `src/`
| الملف | ما فيه |
|---|---|
| `engine.js` | المشغّل (التنقل، المفاتيح، ملاحظات المعلم، الفهرس) وأدوات التفاعل، وجداول الخلفية واللوحة لكل فصل/شريحة (`BGMAP`، `BGID`، `PALCH`، `PALID`) |
| `bg.js` | محرك الخلفيات: ضوء WebGL وخمسة مشاهد Canvas (ذري، تفاعلات، جدول دوري، روابط، عضوية) ولوحات ألوان |
| `motion.js` | الانتقالات (١٦ نوعاً) وحركات دخول العناصر (٢٠ حركة) |
| `style.css`, `theme*.css` | التنسيق؛ `theme4.css` للطبقات واللوحات، `theme5.css` للحركات، ولوحات الألوان في `style.css` (`data-pal`) |
| `art.js`, `assets.js` | الرسوم (SVG بالكود) والصور المقصوصة من عرض NotebookLM بعد تلوينها |
| `deck_a/b/c.js`, `slides_b.js`, `lab_main.js`, `past.js`, `tail.js` | الشرائح بترتيبها |

## الألوان والحركة
- اللوحات: `navy` و`emerald` و`ember` و`gold` (أسود وذهبي) و`violet`. تُختار لكل شريحة بـ `PALID` أو لكل فصل بـ `PALCH`.
- زر الشريط العلوي يبدّل الجودة: كاملة (ضوء + مشاهد + انتقالات متنوعة)، هادئة (انتقالات خفيفة)، ثابتة (إطار واحد). وتنزل الجودة تلقائياً على الأجهزة البطيئة.
- `prefers-reduced-motion` تبدأ بالوضع الهادئ.
