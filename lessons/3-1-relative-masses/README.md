# الدرس ٣-١ · الكتل النسبية (كيمياء الصف العاشر)

درس تفاعلي لعرضه على السبورة أو الحاسوب: ٣٤ شريحة، أسئلة وسحب وإفلات وتصويت وتذاكر خروج، مختبر افتراضي لحرق الماغنيسيوم، وأسئلة من امتحانات سابقة.
الملف الجاهز للفتح: `lesson31.html` (صفحة واحدة بلا مكتبات).

## البناء
```bash
python3 build.py            # يجمّع src/ في lesson31.html
python3 tools/rekey.py      # يعيد توليد src/assets.js من art-src/ (عند تغيير ألوان الرسوم)
```

## الاختبار (من مجلد الدرس، ويحتاج Node وPlaywright)
```bash
node tools/test.js          # كل تفاعلات الشرائح (٣٠ اختباراً)
node tools/residue.js       # لا بقايا حركات بعد التنقل السريع
node tools/overflow.js      # لا تجاوز لحدود الشريحة
node tools/contrast.js      # تباين النصوص فوق الخلفية المتحركة
node tools/perf.js          # زمن الإطار لكل خلفية ولكل مستوى جودة
node tools/tier_test.js     # زر الخلفية (كاملة / هادئة / ثابتة) وحفظ الاختيار
```

## الألوان والحركة
- اللوحات: `navy` و`emerald` و`ember` و`gold` (أسود وذهبي) و`violet`. تُختار لكل شريحة بـ `PALID` أو لكل فصل بـ `PALCH`.
- زر الشريط العلوي يبدّل الجودة: كاملة (ضوء + مشاهد + انتقالات متنوعة)، هادئة (انتقالات خفيفة)، ثابتة (إطار واحد). وتنزل الجودة تلقائياً على الأجهزة البطيئة.
- `prefers-reduced-motion` تبدأ بالوضع الهادئ.


## المظهر (القالب المشترك، نوفمبر ٢٠٢٦)
أُعيد بناء الدرس بنفس قالب الدروس الأخيرة (الوحدات ١ و٢ و٤) دون تغيير المحتوى ولا ترتيب الشرائح:
- **البناء:** `build.py` يستدعي `../_core/tools/u4build.py` بالخيارين `skin='cards'` (خلفيات حية خلف بطاقات ملوّنة صلبة) و`shuffle=True` (خلط ترتيب خيارات الأسئلة فلا تكون الإجابة الصحيحة دائماً الأولى؛ الإجابات مربوطة بـ `data-i` فلا يتأثر التصحيح).
- **الخلفيات:** صور المعلم موزّعة بلا تكرار داخل الدرس على 9 شريحة (goals، calc، table، tk1، tk2، q31، past1، final، hw)، وبقية الشرائح بخلفيات لونية سادة (`p_plain_a..d`) لأنه لا يحب تكرار الصور؛ الشرائح الكثيفة بالتفاعل والجداول خلفيتها سادة ليبقى النص مقروءاً. الخطة في `bgId` داخل `src/config.js`.
- **النقاط بنقرة:** الأهداف (`.gi`) وخلاصة الواجب (`.panel.dark li`) تظهر نقطة نقطة مثل عرض بوربوينت (`pts` في `config.js`).
- **الاختبارات:** تعمل على `?pts=all`، وتختار الخيارات بـ `data-i` لا بترتيبها على الشاشة، وفيها فحص أن شيئاً لا يخرج من الإطار بعد الخطوات (`fits`).
- **الفحوص:** `overflow` و`contrast` (يتجاهل نصاً لم يظهر بعد) و`residue` تعمل على `?pts=all` ويذكر `contrast` رقم الشريحة ومعرّفها.
- **تعديلات صغيرة على الشرائح** لتناسب البطاقات: شريحة الميزان (balance): العمود الجانبي أضيق وخطوطه أصغر؛ تمرين ٣-١ (ب): كتل الذرات في أقراص داكنة؛ المختبر: أسماء معدات السلامة في عناصر مستقلة؛ النماذج: أسماء العناصر في عناصر مستقلة؛ جدول Ar بخط ٢٠

**ترتيب الشرائح الأولى (قرار المعلم النهائي، نوفمبر ٢٠٢٦):** شريحة السماد (NPK) هي الشريحة ٢ بعد الأهداف وقبل «أهمية تحديد كميات المواد» (٣)، فيبدأ الدرس بصورة الكيس كما يبدأ كتاب الطالب (الصورة ٣-١، ص٥٢–٥٣)، ثم الأهمية في الزراعة والبيئة والغذاء، ثم «كيف يتم تحديد كميات الذرات؟». للتاريخ: نُقلت الشريحة إلى آخر الدرس بطلب سابق ثم أُعيدت هنا بعد مراجعة المعلم للكتاب. ولو أراد وضعها قبل الأهداف تماماً فهو تعديل سطر واحد في `src/deck_a.js` (ترتيب التعريف) مع تحديث أرقام `tools/test.js`.


## التدرّج: نقاط تظهر نقرة نقرة (نوفمبر ٢٠٢٦)

بطلب المعلم، لا تظهر شرائح الشرح كلها دفعة واحدة؛ بل تنزل **نقطة نقطة** بزر «التالي» (أو سهم اليسار)، ويرجع زر «السابق» نقطة. عدّاد النقاط يظهر في الشريط السفلي. الترتيب: **التمهيد/السؤال أولاً ← المعلومات بترتيب الشرح ← الخلاصة أو الشريط الذهبي آخراً.** تفاعلات الطلاب (سحب، إدخال أرقام، اختيار) ما تغيّرت؛ التدرّج في الشرح والأسئلة التي حولها.

| الشريحة | ترتيب النقاط |
|---|---|
| ١ الأهداف · ٣٤ الواجب | كل هدف/بند نقطة (كما كان) |
| ٣ أهمية الكميات | بطاقة الزراعة ← البيئة ← الغذاء والدواء ← الأسباب (للسحب) |
| ٧ أسباب اختيار الكربون | العبارة (اقترح العلماء…) ← السؤال «؟» ← لأنه مستقر ← أعداد صحيحة متساوية (6p = 6n) |
| ٨ الميزان | الجولات الثلاث أولاً ← التعريف الذهبي (Ar) بعد الجولة الأخيرة |
| ٩ المقارنة | مقارنة C-12 مع H ← الفلور (زر الخطوات داخل الشريحة كما هو) |
| ١٠ طريقة أخرى (الفلور) | «للعلم» ١ amu = ١٫٦٧×١٠⁻²⁴ g ← التناسب ← المعادلة ← الناتج ١٩ |
| ١١ كم مرة أثقل | صف لكل ذرة (He ← C ← O ← U) |
| ١٢ تمرين الفسفور مع الكربون | السؤال (بصياغة عرضك) ← كتلة P ← كتلة C ← الكسر ٣١/١٢ ← الحساب والنتيجة |
| ١٣ الجدول ٣-٢ | الجدول ← التعليمات |
| ١٤ النظائر | التعريف ← السبب (المتوسط) ← القانون (العنوان نفسه هو السؤال التمهيدي) |
| ١٥ نظائر الهيدروجين | التعريف ← بروتيوم ← ديوتيريوم ← تريتيوم |
| ١٦ الكلور | المسألة ← المعطيات ← الحل (والسهم معه) ← المؤشر والنتيجة |
| ١٨ من الذرات للمركبات | **سؤال تمهيدي (من عندي)** ← الجزيء ← المركب الأيوني ← السؤال الذهبي |
| ١٩ ورشة Mr | التعريف ← H₂ ← H₂O ← NaCl |
| ٢٠ Mr بسيطة | مركب مركب |
| ٢١ Mr معقدة | قاعدة القوس ← قاعدة النقطة ← مركب مركب |
| ٢٢ تمرين ٣-١ (ب) | صف صف |
| ٢٦ التراكيب الضخمة | تركيب تركيب |
| ٢٧ السؤال ٣-١ | مخطط مخطط (A–E وG وH؛ حُذف F) |
| ٢٨ تمرين ٣-١ (أ) | الخط العددي ثم الجمل الأربع واحدة واحدة |
| ٣٠ سؤال نهاية الوحدة | المعادلة ← الفقرة أ ← الفقرات التالية |
| ٣١ و٣٢ امتحانات سابقة | سؤال سؤال |

**بدون نقاط (تتقدّم بتفاعلها أصلاً):** السماد (تصويت ثم كشف)، الخضار والعدّ، أجزاء الذرة، الكربون-١٢ («لماذا؟» ثم البناء ثم السبب)، تذاكر الخروج (سؤال سؤال)، النماذج، المختبر الافتراضي، السباق.

**من عندي (راجعه وقت التحضير):** صياغة السؤال التمهيدي في الشريحة ١٥. ملاحظة: «التعليمات» في الجدول (١٠) صارت على بطاقة داكنة لأن النص على صورة الجدول الدوري كان تباينه ضعيفاً.

**الفحص:** `node ../_core/tools/points_check.js lesson31.html` يتأكد أن كل نقطة تظهر بنقرة وأن السابق يخفيها (٢٤ شريحة · ٩٩ نقطة).

## إضافات بطلب المعلم (نوفمبر ٢٠٢٦)

- **قانون Ar في شريحة النظائر (١٣):** صيغة العرض `% × Am₁X` كانت غير مفهومة، فصارت بالكلمات: Ar = (كتلة النظير ١ × نسبته) + (كتلة النظير ٢ × نسبته) + … مع قاعدة «النسبة تُكتب عشرية (75% = 0.75)» ومثال الكتاب ص٥٤ (الكلور: (35×0.75) + (37×0.25) = 35.5). **من عندي** (الكتاب لا يعطي صيغة رمزية).
- **تمرين الفسفور (١١):** من صورة عرضه، بصياغة السؤال نفسها: «الكتلة الذّريّة لذرّة الفسفور (31) وحدة كتلة ذرّيّة، ما كتلة ذرّة الفسفور بالنسبة لذرّة الكربون؟». كان لوحة صغيرة في شريحة السؤال ٣-٢ وانتقل لشريحته مع الحل بالتدرّج. **من عندي:** الناتج ٢٫٥٨ (٣١÷١٢) لأن الصورة انتهت عند الكسر.
- **طريقة أخرى للفلور (٩):** من صورة عرضه (التناسب: 1 amu ↔ 1.67×10⁻²⁴ g و X ↔ 3.16×10⁻²³ g). تأتي بعد شريحة المقارنة (٨). الناتج ١٩ مثل الطريقة الأولى.

## الدفعة الثانية من ملاحظات المعلم (نوفمبر ٢٠٢٦)

- **أسباب اختيار الكربون (٧):** شريحة جديدة بعد بناء النواة، من صورة عرضه: «اقترح العلماء كتلة ذرّة الكربون ككتلة ذرّيّة ثابتة… » ثم «؟» ثم «لأنه مستقر ويحمل أعداداً صحيحة متساوية من البروتونات والنيوترونات». الكتاب ص٥٤ لا يعلّل الاختيار (يكتفي بأن كتلة C-12 تساوي ١٢ تماماً) فالسبب من عرضه كما هو. **من عندي:** تقسيم الجواب إلى بطاقتين وإضافة 6p = 6n وصياغة سؤال «لماذا اختار العلماء ذرة الكربون؟».
- **سؤال شريحة «من الذرات إلى المركبات» (١٨):** صار «كيف نكتب صيغة المادة من نموذجها؟» (كان «هل تُكتب صيغة كل المواد بالطريقة نفسها؟» وقال المعلم إنه غير مفهوم). **من عندي.**
- **توحيد الأرقام:** كل أرقام الشرائح بالأرقام الغربية (18 = 16 + 2، 2 : 1 ⇒ SiO₂…) كما في مربعات الإجابة والصيغ وكتاب الطالب؛ كان فيها خلط بين ١٨ و18. التحويل في `src/digits.js` (يشمل النصوص التي تظهر لاحقاً كالتغذية الراجعة). شريط المشغّل وملاحظات المعلم يحتفظان بأسلوبهما.
- **تكبير الخط:** تغذية بطاقات Mr (٢٥px بدل ١٨)، شريحة التراكيب الضخمة (النموذج والعدّاد والخيارات)، ورموز الأيونات في السؤال ٣-١.
- **حذف المثال F** (سلسلة C₅H₁₀ ← CH₂) من السؤال ٣-١ بطلب المعلم؛ بقي ترقيم G وH كما في الكتاب. الاسترجاع من تاريخ git (`slides_b.js`) لو أراده.
- **المعادلات اللفظية تبدأ من اليمين:** في شريحة «سؤال نهاية الوحدة» (٣٠) صارت كل معادلة مفروضة اتجاهها (`veq()`): المتفاعلات يميناً، السهم ← لليسار، النواتج يساراً، فلا تنقلب في أي متصفح. وفي الدروس ١-٣ و٤-١ و٤-٢ و٤-٣ حُوّل السهم → بين الكلمات العربية إلى ← (١٩ موضعاً)، وصُحّح سطران في ملاحظات المعلم (١-٣ و١-٤) كانا مكتوبين بترتيب معكوس.
