# الدرس ٣-١ · الكتل النسبية (كيمياء الصف العاشر)

درس تفاعلي لعرضه على السبورة أو الحاسوب: ٣١ شريحة، أسئلة وسحب وإفلات وتصويت وتذاكر خروج، مختبر افتراضي لحرق الماغنيسيوم، وأسئلة من امتحانات سابقة.
الملف الجاهز للفتح: `lesson31.html` (صفحة واحدة بلا مكتبات).

## البناء
```bash
python3 build.py            # يجمّع src/ في lesson31.html
python3 tools/rekey.py      # يعيد توليد src/assets.js من art-src/ (عند تغيير ألوان الرسوم)
```

## الاختبار (من مجلد الدرس، ويحتاج Node وPlaywright)
```bash
node tools/test.js          # كل تفاعلات الشرائح (٣٠ اختباراً)
node tools/residue.js       # لا بقايا حركات بعد التنقل السريع
node tools/overflow.js      # لا تجاوز لحدود الشريحة
node tools/contrast.js      # تباين النصوص فوق الخلفية المتحركة
node tools/perf.js          # زمن الإطار لكل خلفية ولكل مستوى جودة
node tools/tier_test.js     # زر الخلفية (كاملة / هادئة / ثابتة) وحفظ الاختيار
```

## هيكل `src/`
| الملف | ما فيه |
|---|---|
| `engine.js` | المشغّل (التنقل، المفاتيح، ملاحظات المعلم، الفهرس) وأدوات التفاعل، وجداول الخلفية واللوحة لكل فصل/شريحة (`BGMAP`، `BGID`، `PALCH`، `PALID`) |
| `bg.js` | محرك الخلفيات: ضوء WebGL وخمسة مشاهد Canvas (ذري، تفاعلات، جدول دوري، روابط، عضوية) ولوحات ألوان |
| `motion.js` | الانتقالات (١٦ نوعاً) وحركات دخول العناصر (٢٠ حركة) |
| `style.css`, `theme*.css` | التنسيق؛ `theme4.css` للطبقات واللوحات، `theme5.css` للحركات، ولوحات الألوان في `style.css` (`data-pal`) |
| `art.js`, `assets.js` | الرسوم (SVG بالكود) والصور المقصوصة من عرض NotebookLM بعد تلوينها |
| `deck_a/b/c.js`, `slides_b.js`, `lab_main.js`, `past.js`, `tail.js` | الشرائح بترتيبها |

## الألوان والحركة
- اللوحات: `navy` و`emerald` و`ember` و`gold` (أسود وذهبي) و`violet`. تُختار لكل شريحة بـ `PALID` أو لكل فصل بـ `PALCH`.
- زر الشريط العلوي يبدّل الجودة: كاملة (ضوء + مشاهد + انتقالات متنوعة)، هادئة (انتقالات خفيفة)، ثابتة (إطار واحد). وتنزل الجودة تلقائياً على الأجهزة البطيئة.
- `prefers-reduced-motion` تبدأ بالوضع الهادئ.


## المظهر (القالب المشترك، نوفمبر ٢٠٢٦)
أُعيد بناء الدرس بنفس قالب الدروس الأخيرة (الوحدات ١ و٢ و٤) دون تغيير المحتوى ولا ترتيب الشرائح:
- **البناء:** `build.py` يستدعي `../_core/tools/u4build.py` بالخيارين `skin='cards'` (خلفيات حية خلف بطاقات ملوّنة صلبة) و`shuffle=True` (خلط ترتيب خيارات الأسئلة فلا تكون الإجابة الصحيحة دائماً الأولى؛ الإجابات مربوطة بـ `data-i` فلا يتأثر التصحيح).
- **الخلفيات:** صور المعلم موزّعة بلا تكرار داخل الدرس على 9 شريحة (goals، calc، table، tk1، tk2، q31، past1، final، hw)، وبقية الشرائح بخلفيات لونية سادة (`p_plain_a..d`) لأنه لا يحب تكرار الصور؛ الشرائح الكثيفة بالتفاعل والجداول خلفيتها سادة ليبقى النص مقروءاً. الخطة في `bgId` داخل `src/config.js`.
- **النقاط بنقرة:** الأهداف (`.gi`) وخلاصة الواجب (`.panel.dark li`) تظهر نقطة نقطة مثل عرض بوربوينت (`pts` في `config.js`).
- **الاختبارات:** تعمل على `?pts=all`، وتختار الخيارات بـ `data-i` لا بترتيبها على الشاشة، وفيها فحص أن شيئاً لا يخرج من الإطار بعد الخطوات (`fits`).
- **الفحوص:** `overflow` و`contrast` (يتجاهل نصاً لم يظهر بعد) و`residue` تعمل على `?pts=all` ويذكر `contrast` رقم الشريحة ومعرّفها.
- **تعديلات صغيرة على الشرائح** لتناسب البطاقات: شريحة الميزان (balance): العمود الجانبي أضيق وخطوطه أصغر؛ تمرين ٣-١ (ب): كتل الذرات في أقراص داكنة؛ المختبر: أسماء معدات السلامة في عناصر مستقلة؛ النماذج: أسماء العناصر في عناصر مستقلة؛ جدول Ar بخط ٢٠

**ترتيب الشرائح الأولى (قرار المعلم النهائي، نوفمبر ٢٠٢٦):** شريحة السماد (NPK) هي الشريحة ٢ بعد الأهداف وقبل «أهمية تحديد كميات المواد» (٣)، فيبدأ الدرس بصورة الكيس كما يبدأ كتاب الطالب (الصورة ٣-١، ص٥٢–٥٣)، ثم الأهمية في الزراعة والبيئة والغذاء، ثم «كيف يتم تحديد كميات الذرات؟». للتاريخ: نُقلت الشريحة إلى آخر الدرس بطلب سابق ثم أُعيدت هنا بعد مراجعة المعلم للكتاب. ولو أراد وضعها قبل الأهداف تماماً فهو تعديل سطر واحد في `src/deck_a.js` (ترتيب التعريف) مع تحديث أرقام `tools/test.js`.


## التدرّج: نقاط تظهر نقرة نقرة (نوفمبر ٢٠٢٦)

بطلب المعلم، لا تظهر شرائح الشرح كلها دفعة واحدة؛ بل تنزل **نقطة نقطة** بزر «التالي» (أو سهم اليسار)، ويرجع زر «السابق» نقطة. عدّاد النقاط يظهر في الشريط السفلي. الترتيب: **التمهيد/السؤال أولاً ← المعلومات بترتيب الشرح ← الخلاصة أو الشريط الذهبي آخراً.** تفاعلات الطلاب (سحب، إدخال أرقام، اختيار) ما تغيّرت؛ التدرّج في الشرح والأسئلة التي حولها.

| الشريحة | ترتيب النقاط |
|---|---|
| ١ الأهداف · ٣١ الواجب | كل هدف/بند نقطة (كما كان) |
| ٣ أهمية الكميات | بطاقة الزراعة ← البيئة ← الغذاء والدواء ← الأسباب (للسحب) |
| ٧ الميزان | الجولات الثلاث أولاً ← التعريف الذهبي (Ar) بعد الجولة الأخيرة |
| ٨ المقارنة | مقارنة C-12 مع H ← الفلور (زر الخطوات داخل الشريحة كما هو) |
| ٩ كم مرة أثقل | صف لكل ذرة (He ← C ← O ← U) ← سؤال الفسفور |
| ١٠ الجدول ٣-٢ | الجدول ← التعليمات |
| ١١ النظائر | التعريف ← السبب (المتوسط) ← القانون (العنوان نفسه هو السؤال التمهيدي) |
| ١٢ نظائر الهيدروجين | التعريف ← بروتيوم ← ديوتيريوم ← تريتيوم |
| ١٣ الكلور | المسألة ← المعطيات ← الحل (والسهم معه) ← المؤشر والنتيجة |
| ١٥ من الذرات للمركبات | **سؤال تمهيدي (من عندي)** ← الجزيء ← المركب الأيوني ← السؤال الذهبي |
| ١٦ ورشة Mr | التعريف ← H₂ ← H₂O ← NaCl |
| ١٧ Mr بسيطة | مركب مركب |
| ١٨ Mr معقدة | قاعدة القوس ← قاعدة النقطة ← مركب مركب |
| ١٩ تمرين ٣-١ (ب) | صف صف |
| ٢٣ التراكيب الضخمة | تركيب تركيب |
| ٢٤ السؤال ٣-١ | مخطط مخطط (A–H) |
| ٢٥ تمرين ٣-١ (أ) | الخط العددي ثم الجمل الأربع واحدة واحدة |
| ٢٧ سؤال نهاية الوحدة | المعادلة ← الفقرة أ ← الفقرات التالية |
| ٢٨ و٢٩ امتحانات سابقة | سؤال سؤال |

**بدون نقاط (تتقدّم بتفاعلها أصلاً):** السماد (تصويت ثم كشف)، الخضار والعدّ، أجزاء الذرة، الكربون-١٢ («لماذا؟» ثم البناء ثم السبب)، تذاكر الخروج (سؤال سؤال)، النماذج، المختبر الافتراضي، السباق.

**من عندي (راجعه وقت التحضير):** صياغة السؤال التمهيدي في الشريحة ١٥. ملاحظة: «التعليمات» في الجدول (١٠) صارت على بطاقة داكنة لأن النص على صورة الجدول الدوري كان تباينه ضعيفاً.

**الفحص:** `node ../_core/tools/points_check.js lesson31.html` يتأكد أن كل نقطة تظهر بنقرة وأن السابق يخفيها (٢١ شريحة · ٨٨ نقطة).
