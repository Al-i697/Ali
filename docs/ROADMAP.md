## غير مُنفَّذ بعد (بصراحة)

| البند | ملاحظة |
|---|---|
| **مزوّد نموذج محلي للمساعد الذكي** | الواجهة جاهزة لمزوّد جديد ([AI-EXTENSION](AI-EXTENSION.md#إضافة-مزوّد-جديد))؛ المزوّد الوحيد الآن Claude (سحابي). مهم لمدارس تمنع الإرسال لخارج شبكتها |
| **تجربة المساعد الذكي على الخدمة الحقيقية** | لم تحدث (لا مفتاح في بيئة التطوير). تُنفَّذ بـ`ai-check` ثم بتجربة معلم فعلية |
| الحضور والغياب اليومي | خارج المتطلبات الأصلية (وطلب المالك صراحةً أن تكون الأولوية لإدارة الصف لا للحضور)؛ الغياب مدعوم داخل رصد التقويم فقط |
| المصادقة الثنائية (2FA) | غير منفَّذة |
| استعادة كلمة المرور بالبريد | غير منفَّذة عمدًا (لا خدمة بريد) — المدير يعيّن مؤقتة |
| تصدير/استيراد بيانات معلم واحد | خارج النسخ الاحتياطي الكامل |
| تعدد المدارس/المؤسسات (hierarchy) | كل معلم حساب مستقل؛ لا مدير مدرسة يرى تقارير معلميه |
| تطبيق جوال أصلي / PWA غير متصلة | الواجهة تعمل على المتصفح؛ لا وضع عدم اتصال |
| اختبار على Safari/Firefox وأجهزة فعلية | اختُبر على Chromium فقط |
| بناء صورة Docker | الملفات مكتوبة ولم تُبنَ في بيئة التطوير |

## الأولويات المقترحة للمراحل التالية

0. **تعميق إدارة الصف** ([CLASSROOM](CLASSROOM.md#حدود-معروفة)): وضع غير متصل بطابور ضغطات يُرسَل عند عودة الاتصال، وأسباب سلوك شخصية قابلة للضبط، وعتبات المؤشرات من الإعدادات، واقتراح درجة «المشاركة الصفية» في دفتر التقويم من نسبة المشاركة المسجَّلة (بقرار المعلم).

1. **تعميق سجل المختبر**: ربط النشاط بنواتج التعلم والمهارات المرصودة، ومرفقات (صور/ملفات — يتطلب تخزين ملفات ونسخها احتياطيًا)، وحجز المختبر وكشف تعارض الحصص بين المعلمين (يحتاج دورًا على مستوى المدرسة).
2. **تعميق الخطط**: ربط الخطة بمهارات محددة من «المهارات»، وقوالب خطط جاهزة قابلة للمشاركة، وإشعارات المراجعة.
3. **2FA (TOTP)** للمدير على الأقل، وقفل الدخول حسب عنوان IP إضافة للحساب. *(أُجِّلت بطلب المالك لما بعد المساعد الذكي.)*
4. **تصدير بيانات معلم** كاملًا (ZIP: Excel + PDF لكل شعبة) ونقلها لحساب آخر.
5. **دور «مدير مدرسة»** بصلاحية قراءة تقارير معلميه المجمَّعة (بموافقتهم).
6. **PWA** (تثبيت على الجوال + نسخة مقروءة دون اتصال للجدول والقوائم).
7. **المساعد الذكي — ما بعد النسخة الأولى:** مزوّد نموذج محلي، ومهام جديدة (مثل مراجعة صياغة الأهداف أو تبسيط شرح)، وربط اقتراحات التقويم بإنشاء تقويم فعلي في شبكة الدرجات، وقياس رضا المعلمين عن جودة المسودات لاختيار النموذج الأنسب كلفةً.
8. الانتقال إلى PostgreSQL إن تجاوز الاستخدام مدرسة واحدة.

## ديون تقنية معلومة

- الهجرات خمس (`0000_init` الأساس، `0001_support_plans`، `0002_lab_activities`، `0003_app_settings`، `0004_class_management`)، والأربع الأخيرة إضافية (جداول جديدة فقط) ويغطي `tests/server/upgrade.test.ts` ترقية قاعدة قديمة ببيانات حقيقية عبرها (ويثبت أن الترقية لا تفعّل المساعد الذكي). المشروع لم يُنشر بعد؛ بعد أول نشر حقيقي لا تُعدَّل أي هجرة موجودة.
- حزمة الواجهة الرئيسية ~410 ك.ب (127 ك.ب مضغوطة) + حزمة مكوّنات ~250 ك.ب؛ كافية، ويمكن تقسيمها أكثر.
- الخطوط تُضمَّن بصيغتي woff2 وwoff في البناء؛ يمكن إسقاط woff لتقليل الحجم.
- فحوص إمكانية الوصول المؤتمتة بسيطة (أسماء العناصر التفاعلية)؛ لا تدقيق شامل بقارئ شاشة.
