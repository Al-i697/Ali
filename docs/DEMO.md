# المعاينة التفاعلية (للعرض بلا تثبيت)

ملف HTML واحد يحوي **واجهة التطبيق الحقيقية** كاملة مع بيانات مسجَّلة من نسخة تعمل فعلًا، فيُفتح في أي متصفح أو يُنشر كصفحة (مثل Artifact في Claude) **بلا خادم ولا قاعدة بيانات**. الغرض عرض شكل التطبيق وتنقّله وتجربة **«إدارة الصف» فعليًا** (التسجيل في الذاكرة) والمساعد الذكي، **وليس بديلًا عن التطبيق**: لا يحفظ شيئًا بعد إعادة تحميل الصفحة ولا يُستعمل لبيانات حقيقية.

> للاستعمال الفعلي شغّل التطبيق نفسه ([README](../README.md#التشغيل-السريع)) أو انشره ([DEPLOYMENT](DEPLOYMENT.md)).

## ما الذي تقدّمه المعاينة وما لا تقدّمه

| تعمل | لا تعمل (بقصد) |
|---|---|
| كل صفحات المعلم: لوحة التحكم، الشعب وملفات الطلاب، التحضير وجدول الأسبوع، شبكة الدرجات، الخطط، المختبر، الجدول، المهام والتقويم الدراسي، التقارير (معاينتها)، الإعدادات | **الحفظ والتعديل والحذف في كل الأقسام عدا «إدارة الصف»**: أي تعديل يُرفض برسالة «هذه معاينة للتصفح فقط…». الاستثناء تفضيلات العرض (السمة، شكل الأرقام) أثناء الجلسة |
| **«إدارة الصف» تعمل فعليًا في الذاكرة** ([CLASSROOM](CLASSROOM.md)): افتح حصة اليوم، سجّل «شارك ×n» و«لم يشارك» وسلوكًا بأسباب جاهزة وملاحظات، عدّل واحذف مع «تراجع»، و«لم يشارك» لمن تبقّى، ثم شاهد الأثر في الملخص وتبويب «الصف» بملف الطالب وبطاقة لوحة التحكم، **وتقريرَي الطالب والشعبة** (يولَّدان حيّين بعارض الخادم نفسه) | تجربتك **تُمحى عند إعادة تحميل الصفحة** (لا حفظ دائم)؛ والمشاركات المسجَّلة قبل اللقطة هي بذرة البيانات الوهمية؛ ولا تنزيل PDF/Excel لهذه التقارير ولا طباعتها |
| التاريخ مثبَّت على **الثلاثاء 13 أكتوبر 2026، 9:30 صباحًا (مسقط)** — يوم دراسي فيه حصتان — فتتطابق التواريخ والحصص والمهام المتأخرة | تنزيل PDF وExcel، والطباعة وفتح التقرير في نافذة: تُظهر رسالة أنها تعمل في التطبيق الكامل |
| **المساعد الذكي بردود جاهزة** (بلا أي اتصال): نافذة الإدخال ← جارٍ الإعداد ← المراجعة ← الإدراج، مع حماية الأرقام وأسماء الطلاب نفسها | الردود نموذجية تتشكل من العنوان الذي تكتبه؛ ليست من نموذج حقيقي. مزوّدها في الواجهة يُسمّى «مساعد المعاينة (ردود جاهزة)» ولا يدّعي غير ذلك |
| الوضع الفاتح والداكن (يتبع النظام) والجوال | صفحات المدير (المستخدمون والنسخ الاحتياطي وتبويب المساعد الذكي): الحساب المعروض حساب معلم |
| | بيانات لم تُسجَّل: فلتر أو أسبوع أو طالب خارج ما سُجِّل يعرض قائمة فارغة أو «غير مضمّنة في المعاينة» (التقارير لا تُعيد أبدًا تقرير طالب أو مقرر آخر) |

## كيف تعمل

```
npm run build               الخادم والواجهة العاديان
npm run demo:record         يبذر الحساب التجريبي بساعة مثبَّتة، ويشغّل الخادم الإنتاجي، ويتجوّل بمتصفح حقيقي
                            في كل الصفحات ويسجّل كل استجابة GET ناجحة  →  dist-demo/data.json
npm run demo:build          يبني الواجهة بنمط المعاينة ويدمج الأنماط والخطوط والبيانات في ملف واحد
                            →  dist-demo/sijilli-preview.html
npm run demo:verify         يفحص الملف المبني داخل إطار معزول بسياسة CSP صارمة (كما تعرضه المنصة)
```

| المكوّن | الملف | وظيفته |
|---|---|---|
| علمان في التطبيق | `src/web/App.tsx` · `components/layout/app-shell.tsx` | يُفعَّلان بالثابت `VITE_DEMO` عند بناء المعاينة فقط: راوتر في الذاكرة (الإطار المعزول لا يسمح بتغيير عنوان الصفحة)، ونص لافتة المعاينة. في أي بناء آخر يُطوى الثابت ولا أثر له |
| الساعة المثبَّتة | `demo/fake-now.mjs` | `node --import`: يثبّت «الآن» في الخادم وعملية البذر على لحظة التسجيل، فتُحسب التواريخ كلها عليها |
| المسجِّل | `demo/record.mjs` | بذر ← تشغيل (بحدّ طلبات مرفوع لخادمه المؤقت) ← جولة (روابط، تبويبات، خيارات، قوائم، أسابيع وأشهر، معرّفات كل طالب وتحضير وخطة، مصفوفة التقارير) ← حفظ الاستجابات. لـ«إدارة الصف» يحفظ **تقرير كل طالب الخام بكل حصصه** (`/class/students/:id?limit=500`) ويُسقط باقي استجاباتها لأن المحرّك يخدمها |
| محرّك إدارة الصف | `demo/class-engine.ts` | يبذر صفوف المشاركة والسلوك من تلك التقارير الخام ويخدم `/api/class/*` من الذاكرة بقراءاتها وكتاباتها (بالمخططات نفسها `src/shared/schemas/classroom.ts` فيرفض ما يرفضه الخادم: حصة مستقبلية، تسجيل بلا سبب، عدّاد زائد، طالب خارج الشعبة)، ويعدّل لوحة التحكم المسجَّلة، ويولّد تقريرَي الصف بـ`class-docs.ts` و`render.ts` نفسيهما. أرقامه وشاشاته تُبنى بالدوال النقية نفسها (`src/shared/classroom*.ts`) التي يستعملها الخادم فلا تتباعد |
| الطبقة الوسيطة | `demo/shim.ts` | تعمل في الصفحة قبل التطبيق: تعيد الاستجابات المسجَّلة بدل `fetch('/api/…')`، وتحوّل `/class/*` إلى المحرّك، وترفض باقي التعديلات، وتثبّت الساعة، وتحاكي المساعد، وتعالج الطباعة والتنزيل |
| البناء | `demo/build.mjs` | Vite (IIFE، الأصول مضمَّنة data URI، خط woff2 فقط) + esbuild للطبقة الوسيطة، ثم دمج الكل في ملف HTML بلا `<html>`/`<head>`/`<body>` (المنصة تضيفها) |
| الفحص | `demo/verify.mjs` | إطار `sandbox` بلا `allow-same-origin` + CSP تمنع الشبكة والسكربتات الخارجية و`eval`؛ تجوّل كامل، **تجربة تسجيل فعلية في «إدارة الصف»** (مشاركة وتراجع و«لم يشارك» وسلوك وأثرها في الملخص وملف الطالب ولوحة التحكم وتقريريها الحيّين ورفض الحدود)، المساعد وحمايته، التعديل المرفوض في غيرها، التقارير، السمة، الجوال، والتحميل المباشر |

مفتاح الاستجابة المسجَّلة: المسار + المعاملات مرتّبة وبلا فارغ (`demo/key.mjs` — ملف واحد يستعمله المسجِّل والطبقة الوسيطة فلا ينحرفان).

## متى تُعاد العملية

عند تغيير الواجهة أو الـAPI: البيانات لقطة من الاستجابات فلا تعرف مسارًا أو حقلًا جديدًا حتى يُعاد `demo:record`. الملفات الناتجة في `dist-demo/` وهي خارج Git عمدًا (مولَّدة، وبعضها ضخم).

## الأمان والخصوصية

- البيانات كلها من الحساب التجريبي (أسماء مولَّدة عشوائيًا)، ولا يحوي الملف مفاتيح أو كلمات مرور أو بيانات حقيقية. أُفرغ عنوان IP في قائمة الجلسات.
- الطبقة الوسيطة تعترض `/api/…` فقط؛ لا شبكة ولا تخزين دائم (التفضيلات وتسجيلات «إدارة الصف» في الذاكرة وتُمحى بإعادة التحميل).
- المساعد في المعاينة لا يتصل بأي خدمة: ردوده نصوص جاهزة داخل الملف.

## حدود معروفة

- **تحقّقتُ منه محليًا فقط** داخل متصفح Chromium وإطار معزول يحاكي قيود المنصة؛ سلوكه الفعلي داخل أي منصة عرض يعتمد على قيودها (مثل السماح بإطار `srcdoc` لمعاينة التقارير).
- لا تعمل بيانات اليوم الحقيقي: التاريخ مثبَّت عمدًا؛ ومن يترك الصفحة مفتوحة يرى الوقت يمضي من 9:30 لا من الساعة الفعلية.
- التقاط ما لم تلمسه الجولة (حالة نادرة أو فلتر غير معتاد) غير مضمون؛ أضفه إلى `record.mjs` عند الحاجة.
- **المحرّك يعيد ما يعيده الخادم في الحالات الأساسية فقط**: لا يقلّد سجل العمليات ولا العزل بين المعلمين ولا قيود القاعدة (هذه مغطاة باختبارات الخادم الحقيقية). والتقارير الحيّة HTML فقط: PDF وExcel الحقيقيان لا يُنزَّلان من المعاينة.
- لا يُعاد تسجيل بذرة «إدارة الصف» إلا بـ`npm run demo:record`؛ وإن غُيّر شكل DTO لإدارة الصف فأعد التسجيل والبناء.
